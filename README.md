# RentFleet

RentFleet is a full-stack vehicle rental and fleet management platform designed to provide a modern, responsive, and user-friendly vehicle booking experience.

## 🌐 Live Website

[Visit RentFleet](https://rentfleet-client.vercel.app)

## ✨ Features

- Modern and responsive user interface
- Vehicle browsing and category filtering
- Vehicle search and availability checking
- Customer registration and login
- Online vehicle booking
- Booking history and cancellation
- Separate admin dashboard
- Vehicle image upload and management
- Customer and staff management
- Role-based access control
- Vehicle checkout and return management
- Payment and expense management
- Vehicle maintenance tracking
- Business analytics and CSV reports
- MongoDB Atlas integration
- Separate frontend and backend architecture

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML | Web Page Structure |
| JavaScript | Frontend Development |
| CSS | UI Design and Styling |
| Node.js | Backend Development |
| REST API | Client-Server Communication |
| MongoDB Atlas | Cloud Database and Image Storage |
| Vercel | Cloud Hosting |
| GitHub | Version Control |

## 🔐 Security

- Environment-based credential management
- Server-side authentication
- Secure password hashing
- HttpOnly session cookies
- Protected admin API routes
- Role-based authorization
- CORS configuration
- Server-side booking validation
- Double-booking prevention
- Authentication rate limiting
